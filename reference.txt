1. OpenCV  (opencv-contrib-python)
--------------------------------------------------------------------------------
Version  : >= 4.8
Website  : https://opencv.org/
Source   : https://github.com/opencv/opencv  /  https://github.com/opencv/opencv_contrib
License  : Apache License, Version 2.0
           https://www.apache.org/licenses/LICENSE-2.0

Used for :
  - Image I/O (cv2.imread, cv2.imwrite)
  - Color-space conversions (cv2.cvtColor, COLOR_BGR2GRAY, COLOR_BGR2Lab, etc.)
  - Mask drawing (cv2.fillConvexPoly)
  - Image blending (cv2.addWeighted)
  - Telea inpainting (cv2.inpaint with INPAINT_TELEA) — see algorithm ref. [A]
  - Navier-Stokes inpainting (cv2.inpaint with INPAINT_NS) — see algorithm ref. [B]
  - Shift-Map inpainting (cv2.xphoto.inpaint with INPAINT_SHIFTMAP) — see algorithm ref. [C]
    Note: Shift-Map support requires the opencv-contrib-python package.

 ALGORITHM REFERENCES
================================================================================

[A] TELEA INPAINTING (cv2.INPAINT_TELEA)
    Alexandru Telea,
    "An Image Inpainting Technique Based on the Fast Marching Method,"
    Journal of Graphics Tools, vol. 9, no. 1, pp. 23–34, 2004.
    DOI: 10.1080/10867651.2004.10487596

[B] NAVIER-STOKES INPAINTING (cv2.INPAINT_NS)
    Marcelo Bertalmio, Andrea L. Bertozzi, Guillermo Sapiro,
    "Navier-Stokes, Fluid Dynamics, and Image and Video Inpainting,"
    Proceedings of the IEEE Conference on Computer Vision and Pattern
    Recognition (CVPR), vol. 1, pp. 355–362, 2001.
    DOI: 10.1109/CVPR.2001.990497

[C] SHIFT-MAP INPAINTING (cv2.xphoto.INPAINT_SHIFTMAP)
    Yoav HaCohen, Eli Shechtman, Dan B. Goldman, Dani Lischinski,
    "Non-Rigid Dense Correspondence with Applications for Image Enhancement,"
    ACM Transactions on Graphics (SIGGRAPH 2011), vol. 30, no. 4, article 70, 2011.
    DOI: 10.1145/2010324.1964966

[D] APRILTAG (tag36h11, tag25h9, tag16h5 families)
    Edwin Olson,
    "AprilTag: A Robust and Flexible Visual Fiducial System,"
    Proceedings of the IEEE International Conference on Robotics and
    Automation (ICRA), pp. 3400–3407, 2011.
    DOI: 10.1109/ICRA.2011.5979561

[E] APRILTAG 2 (detection pipeline improvements)
    John Wang, Edwin Olson,
    "AprilTag 2: Efficient and Robust Fiducial Detection,"
    Proceedings of the IEEE/RSJ International Conference on Intelligent
    Robots and Systems (IROS), pp. 4193–4198, 2016.
    DOI: 10.1109/IROS.2016.7759617

[F] APRILTAG 3 / STANDARD FAMILIES (tagStandard41h12, tagStandard52h13)
    Maximilian Krogius, Alex Haggenmiller, Edwin Olson,
    "Flexible Layouts for Fiducial Tags,"
    Proceedings of the IEEE/RSJ International Conference on Intelligent
    Robots and Systems (IROS), pp. 1898–1903, 2019.
    DOI: 10.1109/IROS40897.2019.8968053
