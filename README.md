# AprilTagCleaner

-----> [Download the portable app from here!](https://github.com/Riccardo-Foschi/AprilTagCleaner/releases/download/v1.0.0/AprilTagCleaner.exe)<-----

A tool to detect and remove various families of AprilTags from a set of pictures
it supports:
- creation of a PDF ready to print with proper pagination of AprilTags (36h11, 25h9, 16h5)
- add individual images or entire folders for processing
- sequential renaming
- downsampling of image resolution
- scan listed images to find tags (36h11, 25h9, 16h5, Standard41-h12, Standard52-h13)
- Cleanup tags from all images
- manual navigation of the images with mask overlay to check the tag detection before export
- manual editing of tag masks in case of errors
